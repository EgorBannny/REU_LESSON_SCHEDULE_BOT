# REU LESSON SCHEDULE

Telegram-бот: [@REU_LESSON_SCHEDULE_BOT](https://t.me/REU_LESSON_SCHEDULE_BOT)

Версия: 0.1.0 (Фазы 1-3 готовы)

## Что делает

Бот отдаёт расписание занятий СПО Спартаковская — филиала РЭУ им. Г.В. Плеханова
в Брянске (https://www.rea.ru/structure/filials/bryansk/studentu). При `/start`
пользователь один раз выбирает свою группу и попадает в меню (кнопки под
сообщением или команды), откуда может получить:

- расписание своей группы,
- расписание всех групп,
- расписание произвольной другой группы,
- сменить свою группу.

Расписание отдаётся за последние 2 дня, для которых оно опубликовано (бот
уточняет, за какой из них показать), в виде красивой картинки-карточки
(синяя тема).

Источник данных — не сам сайт rea.ru, а опубликованная Google-таблица, на
которую там ведёт кнопка "Расписание" (СПО Спартаковская). Бот скачивает и
разбирает её HTML напрямую.

## Статус

- [x] Фаза 1 — парсер Google Sheets HTML в структурированное расписание (`schedule_bot/scraper.py`, `models.py`)
- [x] Фаза 2 — кэш в SQLite (`schedule_bot/storage.py`) + рендер карточек-картинок (`schedule_bot/render.py`)
- [x] Фаза 3 — Telegram-бот на aiogram (`schedule_bot/telegram/`): диалог с FSM-состояниями на выбор группы, меню на кнопках/командах, отправка картинок
- [ ] Фаза 4 — фоновый поллинг и автопуш подписчикам при появлении нового расписания

## Запуск бота

```bash
cp .env.example .env   # вписать BOT_TOKEN от @BotFather
uv run bot.py
```

## Запуск демо парсера/рендера (без Telegram)

```bash
uv run main.py
```

Скачивает и парсит расписание, сохраняет в `schedule.db` (SQLite, в .gitignore),
рендерит карточку для одной группы и карточки для всех групп последнего дня в
`renders/` (тоже в .gitignore).

## Структура

- `schedule_bot/scraper.py`, `models.py` — скачивание и разбор расписания.
- `schedule_bot/storage.py` — SQLite-кэш расписания + группа каждого пользователя.
- `schedule_bot/render.py` — рендер карточек-картинок (в файл или в память).
- `schedule_bot/telegram/` — сам бот: `states.py` (FSM), `keyboards.py`,
  `handlers.py` (диалог), `app.py` (сборка и запуск).
- `bot.py` — точка входа бота, `main.py` — демо парсера/рендера без Telegram.
